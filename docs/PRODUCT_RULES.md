# Правила публикации товаров на Dorify

> Вкратце: аптека сама управляет своим каталогом. Новые товары
> публикуются сразу, но администратор может скрыть товар при нарушении.
> UI-версия — на странице `/rules` в TWA, ссылка из формы добавления товара.

---

## Кратко

Аптека прошла верификацию (телефон, лицензия). Мы доверяем добавление
товаров. Каждый новый товар появляется в каталоге покупателей сразу.

Если товар нарушает правила — модератор скрывает его и присылает
уведомление аптеке с причиной. Аптека исправляет и создаёт товар заново.

При повторных нарушениях аптека может быть деактивирована.

---

## Запрещённые товары

- Наркотические средства и психотропные вещества из Списка I-IV без специальной лицензии.
- Контрафактные или поддельные препараты.
- Препараты с истёкшим сроком годности.
- БАДы, маркированные как лекарства, с заявленной лечебной эффективностью без подтверждения.
- Любые товары, продажа которых запрещена законодательством Республики Узбекистан.

## Требования к карточке товара

- **Название** — достоверное, без рекламных лозунгов и капслока.
- **Производитель и действующее вещество** — корректные значения.
- **Остаток на складе** — соответствует фактическому количеству.
- **Цена в сумах** — без скрытых наценок.
- **Описание** — не содержит ложных обещаний о свойствах препарата.

## Фотографии

- Без чужих водяных знаков и логотипов сторонних магазинов.
- Желательно реальная фотография упаковки, не stock-картинка.
- Без агрессивной графики (стрелки, рамки, акционные плашки).

## Рецептурные препараты

- Помечайте флагом «По рецепту» при добавлении товара.
- Продажа покупателю — только при наличии рецепта. Ответственность за
  проверку рецепта несёт аптека.

## Что делает модератор при нарушении

1. Скрывает товар (не удаляет — данные сохраняются для аудита).
2. Отправляет аптеке Telegram-уведомление с причиной скрытия.
3. Аптека исправляет недочёты и создаёт товар заново.
4. При повторных нарушениях аптека может быть деактивирована.

## Вопросы и связь

По вопросам правил и спорным ситуациям — поддержка через Telegram-бот
[@dorify](https://t.me/dorify).

## Как изменить эти правила

Эти правила одновременно живут в двух местах:

- `docs/PRODUCT_RULES.md` (этот файл) — source of truth для команды.
- `apps/web/src/features/rules/RulesPage.tsx` — UI-страница, которая
  показывается аптеке.

Любое изменение правил применяется в оба места одним PR. В долгосрочной
перспективе планируется markdown-loader (этот файл → React component
автоматически), но для MVP синхронизация ручная.
